# Task5
 Capture and Analyze Network Traffic Using Wireshark. 

 📝 Overview
This repository contains the deliverables for Task 5: Capture and Analyze Network Traffic Using Wireshark. The objective of this task was to capture live network packets using the Wireshark tool and identify basic network protocols and traffic types.


🛠️ Tools Used

Wireshark: A free and open-source network protocol analyzer.

📦 Deliverables

wireshark_capture.pcap: The raw packet capture file.


This README: A short report summarizing the identified protocols.

⚙️ Steps Performed
Wireshark Installation

Wireshark was installed using the command: sudo apt install Wireshark.

Traffic Generation and Capture

Capture was initiated on the active network interface (eth0) in Wireshark.

Network traffic was generated by running the command ping google.com in a terminal.

The capture was stopped after approximately one minute.

Packet Filtering and Identification

The captured packets were filtered by protocol to identify different traffic types.

The main protocols identified in the capture were DNS, ARP, ICMP, and MDNS.

Export

The captured data was exported as a .pcap file named wireshark_capture.pcap using the File > Export Specified Packets option.

🔍 Protocols Identified and Findings Summary
During the analysis, the following protocols and traffic details were noted:

Protocol	Description	Observed Traffic Details
ICMP	
Internet Control Message Protocol.

Observed as echo request/reply pairs, corresponding to the ping google.com activity. Request IP was 192.168.136.129 and the Reply IP was 142.251.221.110.


DNS	
Domain Name System.

Requests for www.google.com and corresponding responses were captured.

ARP	
Address Resolution Protocol.

Multiple ARP requests were detected, which are used for local IP-to-MAC address resolution on the network.

MDNS	
Multicast DNS.

Local network name resolution traffic, including standard queries and responses, and service discovery.
